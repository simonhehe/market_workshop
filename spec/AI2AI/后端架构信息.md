## 模块外部特性

### 1. 应用入口
- **MallApplication.java**: Spring Boot应用主类
  - 功能: 启动Spring Boot应用
  - 状态: 已实现
  - 依赖: Spring Boot Starter

### 2. 配置模块 (config)
- **CorsConfig.java**: CORS跨域配置
  - 功能: 配置前后端跨域访问
  - 状态: 已实现
  - 配置: 允许所有来源、所有方法、所有请求头

### 3. 通用模块 (common)
- **ApiResponse.java**: 统一API响应格式
  - 功能: 统一前后端API响应结构
  - 状态: 已实现
  - 字段: success, message, data, error, timestamp
  - 方法: success(), error()

### 4. 控制器模块 (controller)
- **HealthController.java**: 健康检查控制器
  - 功能: 提供健康检查和测试接口
  - 状态: 已实现
  - 路由: 
    - GET /api/health - 服务健康检查
    - GET /api/health/test - 前后端连通测试接口
  - 依赖: ApiResponse

### 5. 配置文件
- **application.yml**: 应用配置
  - 功能: 数据库配置、服务器配置、日志配置
  - 状态: 已实现
  - 配置项:
    - 数据库: SQLite, 路径 ./database/mall.db
    - 服务器端口: 8080
    - 上下文路径: /api
    - JPA: ddl-auto=update, show-sql=true

## 技术栈说明

### 核心框架
- **Spring Boot**: 3.2.0
- **Java版本**: JDK 21
- **构建工具**: Maven

### 主要依赖
- **spring-boot-starter-web**: Web框架
- **spring-boot-starter-data-jpa**: JPA数据访问
- **sqlite-jdbc**: SQLite数据库驱动
- **hibernate-community-dialects**: SQLite方言支持
- **lombok**: 代码简化工具

### 数据库
- **类型**: SQLite
- **文件位置**: ./database/mall.db
- **初始化**: 自动创建（JPA ddl-auto=update）

## API接口

### 健康检查接口
- **GET /api/health**: 服务健康检查
  - 响应: 服务状态、时间戳、版本信息
  
- **GET /api/health/test**: 前后端连通测试
  - 响应: 测试消息、技术栈信息、时间戳

## 开发说明

1. **端口配置**: 默认8080，可在application.yml中修改
2. **数据库**: SQLite数据库文件自动创建在backend/database/目录
3. **CORS**: 已配置允许所有来源（开发环境）
4. **日志**: 默认INFO级别，可在application.yml中调整
