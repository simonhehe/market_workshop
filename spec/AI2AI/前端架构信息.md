## 模块外部特性

### 1. API模块 (api)
- **index.js**: Axios实例配置，请求/响应拦截器，自动添加JWT token
- **exports.js**: 统一导出所有API模块
- **auth.js**: 登录、登出接口
- **user.js**: 用户信息查询和更新接口
- **product.js**: 商品列表、详情、搜索接口
- **category.js**: 分类列表接口
- **cart.js**: 购物车CRUD接口
- **order.js**: 订单CRUD接口
- **address.js**: 地址CRUD接口
- **favorite.js**: 收藏CRUD接口

### 2. 路由模块 (router)
- **index.js**: Vue Router配置，包含路由守卫（认证检查、管理员权限检查）

### 3. 组件模块 (components)
- **Layout.vue**: 主布局组件，包含导航栏、用户信息展示、退出登录功能

### 4. 页面模块 (views)
- **Login.vue**: 登录页面，支持测试账号快速填充、回车键登录
- **Home.vue**: 首页，展示分类和热门商品
- **Products.vue**: 商品列表页，支持分类筛选、搜索、排序
- **ProductDetail.vue**: 商品详情页，支持加入购物车、收藏
- **Cart.vue**: 购物车页面，支持数量调整、删除、结算
- **Orders.vue**: 订单列表页，支持查看详情、取消订单
- **OrderDetail.vue**: 订单详情页
- **Profile.vue**: 个人中心页，展示用户信息
- **Favorites.vue**: 收藏页面，支持取消收藏
- **admin/Dashboard.vue**: 管理后台首页
- **admin/Products.vue**: 商品管理页，支持商品列表、删除
- **admin/Orders.vue**: 订单管理页，支持订单状态更新
- **admin/Users.vue**: 用户管理页，支持积分调整

## 路由配置

### 用户路由
- `/login`: 登录页面（无需认证）
- `/`: 首页（需认证）
- `/products`: 商品列表页（需认证）
- `/products/:id`: 商品详情页（需认证）
- `/cart`: 购物车页面（需认证）
- `/orders`: 订单列表页（需认证）
- `/orders/:id`: 订单详情页（需认证）
- `/profile`: 个人中心页（需认证）
- `/favorites`: 收藏页面（需认证）

### 管理员路由
- `/admin`: 管理后台首页（需管理员权限）
- `/admin/products`: 商品管理页（需管理员权限）
- `/admin/orders`: 订单管理页（需管理员权限）
- `/admin/users`: 用户管理页（需管理员权限）

## 认证机制

1. **登录**: 调用`/api/auth/login`获取token，存储到localStorage
2. **Token存储**: token和userInfo存储在localStorage中
3. **请求拦截**: 所有API请求自动在Header中添加`Authorization: Bearer {token}`
4. **响应拦截**: 401错误自动跳转到登录页
5. **路由守卫**: 访问需要认证的页面时检查token，未登录跳转到登录页

## 开发说明

1. **端口配置**: 默认3000，可在vite.config.js中修改
2. **代理配置**: API请求代理到`http://localhost:8080/api`
3. **构建**: 使用`npm run dev`启动开发服务器，`npm run build`构建生产版本
4. **路由模式**: 使用History模式，需要服务器配置支持
