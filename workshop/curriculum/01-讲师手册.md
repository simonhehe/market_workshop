# 讲师手册

> 现场推荐总课件：`curriculum/aecos_workshop_v2.md`（v1 对照：`aecos_workshop.md`）  
> 环境准备：`curriculum/aecos_workshop_prep.md`（深化见 `prep/env-setup.md`）

## 时间盒（现场 180min）

| 分钟 | 阶段 | 讲师动作 |
|------|------|----------|
| 课前 | Track 0 | 按 env-setup + dry-run-checklist 预装；GitNexus analyze |
| 0–15 | P0 | 示范 list_repos 路径匹配；盯缺口清单不偷渡支付 |
| 15–45 | P1 | 卡死「一句话需求」；原型过闸再写 PRD（v2 拆 R-P1-原型 / R-P1-PRD 双段人闸） |
| 45–75 | P2 | 强制对抗 5 题；删不可控 tasks |
| 75–120 | P3 | 切片实现；提醒 create 路由顺序、地址校验前置 |
| 120–155 | P4 | 白名单 scope；达不到 95% 只许 degraded |
| 155–170 | P5 | 真人走查；阻塞修、非阻塞记债 |
| 170–180 | P6 | compass 收口；六件套可给下班或列课后 PR |

## 人闸话术

使用 `workshop/prep/gate-scripts/P*.md`。每闸 3–5 分钟（P5 含操作可达 15 分钟）。  
打回一律发对应 `recovery-cards.md`（R-P0…R-P5），禁止扩大范围「顺便做」。

## 开场话术（2 min）

- 双主线：可演示结算 + 可复训课件。  
- 工具：Cursor + OpenSpec/superpowers + GitNexus + 人闸。  
- 非目标：支付 / 优惠券 / 售后。

## 超时策略

启用金丝雀对照续跑：跳过已预制机械步骤，**保留人闸**；compass 标 `degraded=true`。  
金丝雀**绝不替代**产品方签字。

## 课前检查

见 `workshop/prep/dry-run-checklist.md` 与 `prep/canary/README.md`。  
干跑参考场次：`compass.md` → `unattended-overnight-001`（质量 degraded，勿当「满分示范」口述）。

## 常见现场救场

| 场景 | 动作 |
|------|------|
| 启服 SQLite 报错 | 建 `backend/database/`（env-setup §3） |
| create 进详情页 | 查 router 顺序（playbook） |
| 积分不足刷屏 | 换低积分商品或重置种子积分 |
| 学员要加支付 | 指向负向需求 + R-P1/R-P2 |
