# 人闸 P1 · 产品方（原型 + PRD，各 3–5 min）

## 人闸-原型

1. 原型能否完成：选地址→看合计→提交→看到错误态？  
2. 关键区块是否齐全（地址、商品摘要、积分合计、提交、错误态）？  
3. 是否仍落在中等 MVP（无支付/管理端偷渡）？  

**通过:** 进入 P1-b 写 PRD。  
**打回:** R-P1-原型。

## 人闸-PRD

1. PRD 状态机是否唯一优先级（服务端为状态唯一计算方）？  
2. 负向需求是否清楚（MUST NOT）？  
3. 验收表是否映射到 coverage-scope 最小集？是否与已确认原型一致？  

**通过:** 原型+PRD 与中等 MVP 一致，可进 P2。  
**打回:** R-P1-PRD。
