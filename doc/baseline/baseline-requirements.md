# 基线需求说明（Baseline Requirements）

> 本文档基于当前仓库实现与已有分析文档整理，作为**需求级基线**，便于评审、测试设计与变更对照。未在代码或配置中出现的约束标为 **N/A**。

---

## 1. 产品定位与范围

| 项 | 基线描述 |
|----|----------|
| 产品名 | 企业内部福利商城（后端 `mall-backend` / 前端 `mall-frontend`） |
| 核心价值 | 员工使用**积分**兑换商品；管理员维护商品、订单与用户相关数据 |
| 部署形态 | **N/A**（仓库未约定生产拓扑） |
| 目标用户 | 企业内部员工（`user`）、系统管理员（`admin`） |

---

## 2. 角色与权限（与实现对齐）

| 角色 | 标识 | 能力基线 |
|------|------|----------|
| 注册用户 | `user` | 登录后访问商城、购物车、订单、个人资料、收藏、收货地址、积分流水等；仅能操作与本人 `userId` 绑定的数据（订单详情等接口含校验） |
| 管理员 | `admin` | 在 `user` 能力之外，可访问 `/admin/**`：商品 CRUD、订单列表与状态更新、用户列表、调整用户积分、启停用户、分类维护等 |

**鉴权**：JWT，`Authorization: Bearer <token>`；管理员接口在服务端校验 `role == admin`。

---

## 3. 功能需求基线（按域）

### 3.1 认证与账户

- 用户凭用户名、密码登录；成功返回 Token 及用户标识信息。
- 账户可具有 `active` / `inactive` 状态；非活跃账户登录失败（见 `AuthService`）。
- 密码存储：支持 BCrypt；演示数据中存在明文密码路径（**非生产基线**）。

### 3.2 目录与商品

- 分类列表可匿名访问（过滤器白名单）。
- 商品列表、详情可匿名访问；详情接口含浏览量字段（落库行为以实现为准）。
- 商品含积分价、库存、分类、状态等属性。

### 3.3 购物车

- 登录用户可增删改购物车行、清空购物车；服务端汇总已选件数、预估积分等。
- 购物车行含「是否选中」字段（`isSelected`）；**当前无独立 API 仅更新选中状态**（以实现为准）。

### 3.4 订单

- 用户可从购物车选中行发起下单（服务端以 `isSelected == 1` 行为准）；创建订单扣减积分与库存，生成订单明细，记录积分支出流水，并删除已结算购物车行。
- 用户可查看本人订单列表与详情；可取消**待处理**订单并退回积分、恢复库存（以实现为准）。
- 管理员可查看全部订单、更新订单状态字符串。

### 3.5 收货地址

- 用户可对本人地址增删改查（服务端对更新/删除校验归属）。

### 3.6 积分

- 用户有余额字段；订单消费与取消触发流水记录（类型含 `spend`、`refund` 等）。
- 用户可查询本人积分历史，支持按类型筛选。

### 3.7 收藏与其他

- 收藏接口存在于 `FavoriteController`（路径以代码为准）。

## 5. 假设与约束（来自实现）

- API 统一前缀：`/api`；后端默认端口 `8080`；开发态前端代理 `/api` 至后端。
- 数据库：SQLite 单文件，路径见配置；JPA `ddl-auto: update`。
- JWT 密钥与过期时间见配置文件（**生产需外置与轮换**）。

## 6. 已知与需求缺口（实施前需决策）

以下不影响「记录基线」，但影响**验收口径**：

- 订单状态**管理员可写任意字符串**；与「仅允许若干状态」的需求是否一致 **待产品确认**。
- 匿名可浏览商品是否满足内网商城策略 **待确认**。
- 前端下单页与路由：当前与「完整购物车结算」闭环 **不一致**（见 [order-domain-baseline.md](order-domain-baseline.md) 与 [测试基线建议.md](../analysis/测试基线建议.md)）。
- 仓库**无根 README**、**无自动化测试目录**；CI **N/A**。
