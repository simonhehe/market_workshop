# 项目初始化摘要

> 基于当前代码库梳理（探索分析）。若所在分支曾删除根目录 `README` 与 `spec/`，以下「业务定位」仍可从代码与 `DataInitializer`、登录页推断。

---

## 1. 系统定位与核心业务域

| 维度 | 说明 |
|------|------|
| **定位** | **企业内部福利商城**：员工用**积分**浏览商品、加购、下单、管理地址与收藏；管理员维护商品/订单/用户/分类。 |
| **业务域** | 用户与认证、商品与分类、购物车、订单履约、收货地址、收藏、积分与积分流水、管理后台（CRUD/状态/积分调整）。 |
| **数据形态** | 单体 Spring Boot + 嵌入式 **SQLite**（`backend/database/mall.db`），JPA `ddl-auto: update`，启动时可 **DataInitializer** 灌入演示数据。 |

---

## 2. 主要角色与权限边界

| 角色 | 标识 | 前端 | 后端 |
|------|------|------|------|
| **普通用户** | `role = user`（JWT + `localStorage.userInfo`） | 除 `/admin/*` 外需登录；路由 `requiresAuth` | 受保护接口从 `Authorization: Bearer` 解析 `userId`/`role` |
| **管理员** | `role = admin` | `/admin`、`/admin/products` 等需 `requiresAdmin`，且 `userInfo.role === 'admin'` | `AdminController` 内校验 `role` 为 `admin`，否则 403 |
| **匿名** | 无 token | 仅 `/login` 无鉴权 | `AuthMiddleware` **白名单**：`/`, `/health`, `/auth/login`，以及 **`/products`、`/categories` 及其子路径** 可无 JWT 访问（便于列表/分类公开拉取） |

**测试账号（登录页明文展示）**：`user1/password1`、`user2/password2`、`user3/password3`；管理员 `admin/admin123`。

## 3. 前后端技术栈与关键依赖

**后端（`backend/pom.xml`）**

- **JDK 17**，**Spring Boot 3.2.0**
- **spring-boot-starter-web**、**data-jpa**、**validation**
- **SQLite**：`sqlite-jdbc` + **Hibernate SQLite dialect**（`hibernate-community-dialects`）
- **JWT**：`jjwt` 0.12.3（api/impl/jackson）
- **密码**：`spring-security-crypto`（BCrypt，`JwtConfig` 中 `PasswordEncoder`）
- **Lombok**
- **服务**：端口 **8080**，上下文 **`/api`**（即接口形如 `http://localhost:8080/api/...`）

**前端（`frontend/package.json` + `vite.config.js`）**

- **Vue 3**、**Vue Router 4**、**Axios**
- **Vite 5**，开发端口 **3000**，**`/api` 代理到 `http://localhost:8080`**

**工程辅助**

- **OpenSpec**（`openspec/` + `.cursor/commands` 等）：变更提案工作流；CLI 文档要求 **Node ≥ 20.19**（与前端 Vite 可并存，注意版本）。

## 5. 项目启动方式、运行前提、已知工程风险

### 启动方式（推荐）

1. **后端**：在 `backend` 下使用 **JDK 17**，执行 `./mvnw.cmd spring-boot:run`（或 IDE 运行 `MallApplication`）。  
2. **前端**：在 `frontend` 执行 `npm install`（首次）、`npm run dev`，浏览器访问 **`http://localhost:3000`**。

### 运行前提

- **JDK 17**（与 `pom.xml` 一致；若本机只有 JDK 11/21 需自行对齐或改 `pom`）  
- **Node + npm**（前端；OpenSpec CLI 建议 **Node ≥ 20.19**）  
- **Maven**：可用项目自带 **`mvnw.cmd`**，无需全局 Maven  
- **SQLite**：`backend/database/` 可写；首次启动会建库/表  

### 已知工程风险 / 注意点

1. **安全**：`application.yml` 中 **JWT secret 明文**、默认密钥不适合生产；演示用户存在**明文密码**路径（`DataInitializer`）。  
2. **鉴权与白名单**：`/products`、`/categories` 在过滤器中**整段前缀放行**，与「仅登录可购」的前端路由策略不完全一致，需知悉若对外网暴露的风险。  
3. **脚本**：`backend/start.ps1` 曾在部分环境出现 **PowerShell 解析错误**；更稳妥为直接用 `mvnw.cmd`。  
4. **版本叙事**：历史文档多写 **JDK 21**，而代码已设为 **JDK 17**，以 `pom.xml` 为准。  
5. **前端细节**：如购物车「结算」若指向未定义路由（历史问题）、部分管理功能为占位（如「编辑商品」弹 alert），需按迭代补齐。

---

**一句话**：本项目是 **Vue3 + Vite** 与 **Spring Boot 3 + JPA + SQLite + JWT** 的积分制福利商城演示；用户/管理员双角色，前后端分离，适合本地联调与功能扩展，**生产上线前必须重做密钥、HTTPS、鉴权模型与数据初始化策略**。
